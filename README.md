# odin-calculator
Short Description: A Calculator button based website that allows users to compute simple equations of their choice

Setup Instructions: 
- Open the browser
- Press an input (any number 0-9)
- Press an operator or decimal
- Press another input (any number 0-9)
- Press Equal and out comes your result
- Utilizes: Multi Integer calculations
- Utilizes: Order of Operations
- Happy Calculating!
